# M3U Channels for CloudStream

Extensión de CloudStream para cargar una lista M3U configurada desde la app.

## Instalar

Agrega este repositorio en CloudStream con:

`https://raw.githubusercontent.com/flaviofagroec-a11y/cloudstream1-m3u/main/repo.json`

Cuando termine la compilación automática, instala **M3U Channels** y abre sus ajustes para pegar la URL M3U. La URL queda guardada en los ajustes locales del plugin y no se publica en este repositorio.

La extensión solo lee la lista y entrega los enlaces al reproductor; no aloja contenido.
